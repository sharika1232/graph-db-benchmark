# Future Improvements

The current benchmark framework includes:

- Data loading
- 1-Hop Traversal
- 2-Hop Traversal
- 3-Hop Traversal
- Aggregation
- Point Lookup

The following improvements are planned:

- Mixed read/write workload benchmarking with configurable client concurrency
- Data loading throughput comparison (nodes/sec and relationships/sec)
- Resource usage collection where available
- Additional managed graph database platforms
- Automated benchmark report generation
