## Description

- **src/** contains the benchmark implementation.
- **data/** contains the benchmark dataset.
- **results/** stores benchmark output CSV files.
- **README.md** contains project documentation.
- **RESULTS.md** summarizes benchmark results.
- **ANALYSIS.md** explains benchmark observations.
- **COMPARISON.md** compares benchmarked databases.
- **LOAD_RESULTS.md** contains data loading metrics.
- **METHODOLOGY.md** documents the benchmarking process.
- **LIMITATIONS.md** lists current limitations.
- **FUTURE_WORK.md** outlines planned improvements.
